# Network Engineering Journey

Documentation of my hands-on path toward becoming a network engineer — CCNA study,
virtualization labs, Linux administration, and a physical homelab. This repo is both
my working notes and a portfolio of what I've built and troubleshot along the way.

## About me
Studying for CCNA while building practical experience through VM-based labs and a
home lab environment. Every folder below is a real thing I set up, broke, and fixed.

## Structure

| Folder | What's in it |
|---|---|
| [`virtualization/`](virtualization/) | Windows 11 and Ubuntu Server VMs — setup, configuration, use cases |
| [`linux/`](linux/) | Linux fundamentals: file system, networking, SSH, users & groups |
| [`packet-tracer/`](packet-tracer/) | CCNA labs — OSPF, routing, VLANs — with topology diagrams |
| [`homelab/`](homelab/) | Physical homelab: Raspberry Pi and mini server rack |
| [`automation/`](automation/) | Python scripts for network/sysadmin automation |
| [`engineering-journal/`](engineering-journal/) | Weekly reflections — what I learned, what confused me, what's next |

## Tools & environment
- VirtualBox / VMware
- Cisco Packet Tracer
- Ubuntu Server, Windows 11
- Python 3
